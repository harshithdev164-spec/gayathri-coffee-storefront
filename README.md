# Gayathri Coffee Storefront

A warm, heritage-led ecommerce storefront for Gayathri Coffee, rooted in Mysore and built with the supplied brand guide, logo, product photography, and coffee-house story.

## Run locally

```bash
pnpm install
pnpm --filter @workspace/gayathri-coffee run dev
```

The storefront is frontend-only and includes product discovery, category filtering, search, quick view, favorites, a responsive cart drawer, quantity controls, and mobile navigation.
